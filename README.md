# python-automacao-contabilidade

Este repositório contém uma automação simples realizada em um site . A automação utiliza o navegador EDGE para acessar o site, realizar o login de forma autônoma e posteriormente realizar o preechimento automatico de campos especificos através de dados provenientes de um arquivo docx. A automação foi implementada em Python utilizando algumas bibliotecas listadas na seção inicial.

## Como Usar

1. Clone o repositório:

```bash
git https://github.com/bispobr/python-automacao-consulta.git
```
2. instale o selenium e openpyxl através do pip python
3. execute o arquivo app.py
